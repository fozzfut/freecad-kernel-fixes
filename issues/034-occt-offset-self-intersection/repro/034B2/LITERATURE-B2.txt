DOIs checked by web search 27.09 unless marked [not re-checked].
B2-1. Aomura S., Uehara T. Self-intersection of an offset surface. Computer-Aided Design 22(7):417-421, 1990.
      ScienceDirect pii 001044859090106M (doi 10.1016/0010-4485(90)90106-M). Venue: CAD. [ABS; method summarised in B2-3, OA]
      Idea: self-intersection curves of a (collapsed) B-spline offset: start points by one-dimensional searches,
      curves by integrating an ODE system (tracing).
      Applied: design of the in-face trace (round 3 plan: predictor-corrector on S_d(p) = S_d(q), p != q). Not in code yet.
B2-2. Maekawa T., Cho W., Patrikalakis N.M. Computation of self-intersections of offsets of Bezier surface patches.
      ASME Journal of Mechanical Design 119(2):275-283, 1997. Venue: ASME JMD (IF ~3, NOT in the specialist list -
      supporting source only). [ABS]
      Idea: start points of the self-intersection curves from a polynomial system (interval projected polyhedron);
      trivial solutions p = q removed with normal bounding pyramids.
      Applied: seed search design for round 3 (the trivial diagonal must be excluded by a normal-cone test).
B2-3. Patrikalakis N.M., Maekawa T. Shape Interrogation for CAD/CAM. Springer 2002 (2010 reprint), section 11.3
      "Singularities of offset surfaces" [OA hyperbook web.mit.edu/hyperbook/Patrikalakis-Maekawa-Cho/node225.html].
      Book (specialist). Idea: two singularity kinds of an offset: irregular points / cuspidal edges where a principal
      radius equals the offset, and self-intersection curves that end on them.
      Applied: the class split used here: V = the whole face beyond the cuspidal set (vanishing face, this round);
      P = cuspidal edge inside the face (partial fold, rounds 3-4).
B2-4. Park Y., Son S.-H., Kim M.-S., Elber G. Surface-surface-intersection computation using a bounding volume

      Applied: upgrade path for the rim intersections at the degenerate threshold (offset = blend radius), where the

B2-5. Cheng J.-S., Zhang B., Xiao Y., Li M. Topology driven approximation to rational surface-surface intersection via

Re-used (base file / earlier stages): Farouki 1986 (CAGD) and Maekawa 1999 (CAD): the offset folds where 1 - d*k_i < 0;
Forsyth 1995 (SMA): offset faces may vanish, neighbours are extended and intersected; Rossignac-Requicha 1986 (CAGD):
closing/opening - a closed blend network smaller than the offset is invisible to the offset; Hong 2019 / Park 2021:
miter points = ends of self-intersection curves (numerically unstable in (u,v)); Li-Jia-Chen TOG 2025: certified
self-intersection test (upgrade of the sampled fold test).
Own derivation (recorded here and in the code comment):
  (1) Ball argument. If 1 - d*k_i(x) < 0 for a principal curvature k_i at x (d signed along the outward normal), the
      ball of radius |d| centred at p = x + d*n(x) contains surface points near x, so dist(p, S) < |d| and p is never
      on the offset. A face with this at every point contributes nothing to the offset ("vanishing face").
  (2) Rim lemma. Let Z be a connected set of vanishing faces whose boundary edges are all shared, tangent (G1) edges.
      Every boundary point of the dilation near Z has a nearest point on S at distance |d|; by (1) it is not in Z and
      not on a boundary edge of Z (the Z side folds there too), so it is the offset of an interior point of a
      surviving neighbour ("rim face"). The dilation boundary is closed, so the rim offsets must meet each other inside
      their own parameter domains (on their boundary exactly when the offset equals the blend radius): pairwise
      intersection of the rim offsets is enough, no extension beyond the tolerance is needed.
  (3) Tolerance-degenerate face: min factor * face size <= tolerance => the offset face is below the tolerance in one
      direction (a curve or point) - treated as vanishing, like OCCT's analytic status Degenerated (|R| < Tol).
Better-known method check: for exact trimming of partial folds the literature (B2-1..B2-3, Seong-Elber-Kim 2006,
Pekerman 2008, Park 2021) traces the self-intersection curve; nothing cheaper is known. For vanishing faces
Forsyth's neighbour intersection is the classic kernel method; this round implements it for the tangent-bounded case.
