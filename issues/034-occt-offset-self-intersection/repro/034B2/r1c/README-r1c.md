главный коэффициент 1 − d·k_i ≤ 0 по всей грани), граница которого — не только касательные рёбра, но и ОСТРЫЕ рёбра,

деталь: коробка со скруглёнными только вертикальными рёбрами, одно скруглённое ребро, скругления верхних рёбер над
