### Корень (пункт 2 ревью: «Толщина» L-корпуса, разные радиусы, две снятые грани, касательная крышка)
Раунд 1 заменял ВСЁ сечение грани обода с крышкой сечением увеличенных копий
(`BRepOffset_MakeOffset.cxx` ToContext + `BRepOffset_Inter3d.cxx` ContextIntByArc: `continue` при
`BRepOffset_RimCap034b`). У такого ребра второй конец лежит у НЕисчезающей грани (трубка вогнутого
ребра, уцелевшее скругление). Там сток даёт общую вершину; длинная прямая касалась дуги трубки,
а дуга трубки на крышке вообще не строилась (обработка вершин в ContextIntByArc тоже пропускалась).
Трассировка L t=1.5 (trc/lf): на крышке нет сечения трубки; грани x=1.5 и y=1.5 остались необрезанными.
Второй корень (две крышки, касательная крышка): угол обода со второй крышкой лежит ЗА стоковым концом
(крышка не смещается). Это относится и к сечению обод × крышка, и к сечению двух граней обода по острому ребру.

### Исправление
1. Грань обода, у которой есть ребро на крышке, сохраняет стоковое сечение. Оно продлевается только на
   исчезающем конце — на «досягаемость» набора (размер набора + |d|), по длине дуги. Замкнутая кривая
   продлевается не больше чем на четверть остатка периода с каждого конца. Пары на увеличенных копиях
   остаются только для граней обода без ребра на крышке.
2. Хук в ConnexIntByArc: сечение двух граней обода по острому ребру продлевается так же, если набор
   доходит до крышки.
3. Исчезновение ДОКАЗЫВАЕТСЯ. Порядок проверки:
   - опровержение одной точкой (граница, середина);
   - канонический двойник в допуске грани (GeomConvert_SurfToAnaSurf) и аналитическое правило
     BRepOffset::Surface;
   - иначе интервальные оценки по патчам Безье: оболочки годографов, правило Лейбница, условия
     след/определитель матрицы sigma·I − d·W; оценки берутся в собственной системе патча.

   Недоказанная грань не выбрасывается. Константы выведены:
   - 1e-10 — запас на округление;
   - 4096/24 — только бюджет, не решение;
   - tol/size — вырождение при d = r.
4. Учитываются все интервалы ребра. Боксы обода считаются один раз. Поле Caps удалено.

### Не решено (раунд 3)
1. **Частичные складки** — ядро класса, пункт 1 ревью: Face26 владельца, 5829, переменное скругление
   с r, пересекающим d. Дизайн и литература — `LIT-r2.txt` (C). Интервальная проверка не может
   сертифицировать область с фактором ровно 0 на её границе: нужен региональный сертификат
   (точки-митры, Park–Hong–Kim–Elber 2021, TOG 2025).
2. Соединение Intersection (BuildOffsetByInter): путь исчезающих граней там не подключён.
3. Две NURBS-крышки: ограниченное сечение-B-сплайн.
4. Путь ошибки куба 031 медленнее в 4 раза — это стоимость соединений обода.
