### Код (diff 558b2a4d..bdef38f1, +946/−111, только TKOffset)
1. **Интервальное доказательство исчезновения проверено вывод за выводом:**
   - C1 = 2σ|N|³ − dJ и C2 = σ²|N|⁴ − σd|N|J + d²Q — это след и определитель σI − dW, умноженные на |N|³ и |N|⁴;
   - оболочки годографов с множителями n и n(n−1) верны;
   - формулы Лейбница для рациональных поверхностей верны;
   - поворот в систему хорд патча верен;
   - доказательство идёт по всему UV-прямоугольнику грани, это надмножество грани, значит оценка консервативна;
   - опровержение засчитывается только точкой ВНУТРИ грани;
   - если доказать не удалось, грань сохраняется.

   Ключей модели нет. Бюджет 4096 / глубина 24 ограничивают только цену и не влияют на решение.
2. **(minor)** Арифметика обычная, без направленного округления. Запас 1e-10 берётся относительно модуля ИТОГОВЫХ C1/C2, а не промежуточных слагаемых, где бывает сокращение. Надёжнее округлённая интервальная арифметика (Hu, Patrikalakis, Ye, «Robust interval solid modelling», CAD 28(10) 1996; Hu–Maekawa–Patrikalakis CAD 1997): внешнее округление nextafter для каждой операции, почти бесплатно.
3. **(MAJOR, невыведенный порог)** В LIT-r2 (8) утверждается, что сечения продлеваются на «досягаемость» = диагональ bbox множества + |d| и что это граница («distance ≤ size of the set + |d|»). Это не граница. Для двугранного угла α между гранями обода угол лежит на (d − r)·ctg(α/2) за стоковым концом, и эта величина неограниченно растёт при α → 0. W2: нужно 16–23, досягаемость 7–8.

   Аналитические клинья всё равно дают EXACT: там это продление, судя по всему, не ограничивает результат. Отказ через него я не воспроизвёл, так что тихой ошибки нет. Но порог объявлен выведенным и при этом неверен. Нужно либо вывести настоящую границу (например, пересечь продолжения поверхностей обода с крышкой и взять точку угла), либо обосновать, почему длина не важна, и покрыть это членом-тестом с B-сплайн-сечением.
4. **(minor)** Кап продления периодической кривой в 1/4 остатка периода задан без вывода. Если его не хватает, результат — ошибка, не тихая.
5. **(minor)** T-корпус NURBS d1.5 возвращает результат с BOPAlgo_InvalidCurveOnSurface на 4 рёбрах. Допуск 1e-7 занижен, отклонение лежит в (1e-7, 1e-6]: после fixTolerance(1e-6) проверка чистая. Геометрия точная (sd = 0), fuse и cut с этим результатом дают согласованные объёмы (`out/diagt2-o034b2r2.txt`, `diagt3`). Источник не трассировал.
6. isSwap (какой конец сечения какому концу ребра соответствует) выбирается по сумме расстояний. Это устойчиво, замечаний нет.

### Почему не принято
1. **Ядро класса не реализовано.** Частичные складки: угол 031 / Face26 владельца (off −0.3/−1/+0.3), 5829 local и world (off −0.5/−1, thk −0.5/−1), новый член — эллиптический цилиндр (d = 2 и 3, частичные складки внутри грани). Во всех случаях ERR, честно. По задаче требуется точная обрезка по кривой самопересечения с концами-каспами. Исполнитель сам признаёт, что этого нет.
2. **Цена пути ошибки на кубе владельца:** 13.8 / 9.5 с против 1.6 / 3.1 с в поставке.
3. **Невыведенный порог продления** (Код, п. 3).
4. **Известные пробелы подкласса остаются:**
   - соединение Intersection (PD Thickness Join = Intersection на призмах, vbox NURBS);
   - две NURBS-крышки (hex TOP+SIDE n, L top+front n).
