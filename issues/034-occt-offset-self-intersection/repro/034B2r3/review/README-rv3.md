### Эталоны (независимые)
Эталон — 2D-эрозия ВХОДНОГО профиля:
- сечение призмы после смещения = A ⊖ d (эрозия произведения — это произведение эрозий);
- для тела вращения — эродированное меридианное сечение;
- для косого цилиндра — эродированное перпендикулярное сечение, поднятое вдоль оси.

Эрозия строится так: обрезанные параллельные кривые плотной выборки профиля, скругления в углах, узлование, polygonize. Грань оставляется, если лежит внутри и дальше d от контура (`cmp3.py`, `cmpfam.py`).

- **Самопроверка.** На эллипсе 10/4 при d = 1, 2, 3 мой эталон совпадает с точными квадратурами исполнителя до 2–5e-10.
- **Эталон надёжнее shapely.buffer:** buffer ошибается до 1e-3 (упрощение входа). В 600 точках из области расхождения прав мой эталон (600/600), buffer — 0/600 (`tools/chkrev.py`).
- **Отрицательный контроль:** эталон с d·(1+1e-4) даёт sd 2.6e-5…4.4e-4 против порога 2e-6, то есть ловится (`out/neg-cmp.txt`, `out/famsec-neg.txt`).

### Почему НЕ ПРИНЯТО
1. **Класс не закрыт:**
   - модели владельца 031/Face26 и 5829 (local и world) по-прежнему дают ERR;
   - из моих новых подсемейств ни одно не решено: кольцевая складка тела вращения, косая экструзия, шов на складке, мелкоузловые бампы, вторая линза-островок, двойные складки;
   - Intersection и две NURBS-крышки остались.
2. **Путь ошибки куба владельца по-прежнему в 4–5 раз медленнее;** на мелкоузловых бампах ошибка приходит за 113 с или ответа нет за 300 с.
3. **Недовыведенные пороги в пути сертификата** (D-B2r3-4/5/3).

**СОХРАНИТЬ:** раунд безопасен — 0 тихо неверных в 47 + 50 строках, идентичность как заявлена, D0 = коммит. Тихие ошибки поставки (бампы, спутники, dumbbell) он превращает в ERR. Это хорошая база для r4.
