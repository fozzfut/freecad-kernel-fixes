# Релиз fc26.3-occt8.0.1-alpha1 — патчи для FreeCAD 26.3dev / OCCT 8.0.1

Сырой стартовый релиз: наши исправления ядра и модуля Part, перенесённые с FreeCAD 1.1.1 / OCCT 7.8.1
на FreeCAD 26.3dev weekly 2026.09.23 (git `019f5c5`) и OCCT 8.0.1 (тег `V8_0_1`). От него дальше делаем улучшения.

First raw release: our kernel and Part-module fixes ported from FreeCAD 1.1.1 / OCCT 7.8.1 to the FreeCAD 26.3dev
weekly 2026.09.23 (git `019f5c5`) and OCCT 8.0.1 (tag `V8_0_1`).

## Что внутри

| Папка | Что исправляет | Замер (обычная 26.3 → с патчем, один прогон) |
|---|---|---|
| `occt-8.0.1/001-*` | Скругление ребра на шве цилиндра давало невалидное тело (TKFillet) | неверно → верно |
| `occt-8.0.1/009-*` | Булевы с периодическими поверхностями: Common пустой, Cut с лишним объёмом (TKBO) | неверно → верно |
| `occt-8.0.1/012-*` | Сетка граней с множеством отверстий и длинных граней квадратична (TKMesh); сетка та же до треугольника | винт ШВП 6.4° 169 → 17 с; плита 4.7 → 0.8 с |
| `occt-8.0.1/018-*` | Проверка граней со многими контурами квадратична (TKTopAlgo, BRepCheck), поверх upstream PR #1375 | плита 1024 отв., анализ 3.0 → 0.43 с |
| `occt-8.0.1/020-*` | ShapeFix / FixFaceOrientation квадратичны (TKShHealing), поверх upstream PR #584 | ShapeFix 10.3 → 1.7 с; Refine 12.3 → 2.4 с |
| `freecad-26.3/1-plan-D-*` | После правки заново строится сетка только изменённых граней; точность сетки — настройка (PartGui) | правка Top 345 → 276 мс |
| `freecad-26.3/2-plan-G-*` | Выбор под курсором через BVH для граней и рёбер (PartGui); настройка `Mod/Part/PickBVH` | сцена 1.65 млн треуг.: медиана 30.6 → 0.22 мс |

Каждый патч проверен на совпадение результатов и сообщений со стоковым 26.3 / 8.0.1 (кроме самих исправленных
дефектов): контрольная сборка = сток, сборка «старый и новый код на каждом вызове» с 0 расхождений, мутанты
пойманы, экспорты и импорты DLL равны стоковым. Подробности — в `SERIES.md` каждой папки.

## Сборка

- OCCT: V8_0_1, флаги как в LibPack 3.5.5 (исключения включены, `/EHa`, C++17, `/MD`, без LTCG), MSVC 14.50 — тот же,
  что у weekly. Собирается весь тулкит; DLL — прямая замена стоковой.
- FreeCAD: коммит 019f5c5, LibPack 3.5.5, MSVC 14.44 — тот же, что у weekly. Part.pyd и PartGui.pyd ставятся парой.
- Применять патчи: `git -c core.autocrlf=false apply` (или `git am`).

`MD5SUMS.txt` — суммы собранных файлов из релиза. Бинарники лежат в ассетах релиза на GitHub.

## Известные ограничения

- FreeCAD 26.3dev — сборка для разработчиков. Большие сцены целиком и видимое окно ещё на приёмке.
- Не перенесено: 017 (отложено), 022 (на паузе), 025 (исследование).
